# Atelier — NovelAI 작가 태그 · 그림체 아카이브

설치 없이 브라우저에서 돌아가는 정적 웹앱입니다. 빌드 과정도, 서버도 없고 외부 라이브러리도 쓰지 않아요.
데이터는 **각 기기의 브라우저(IndexedDB)** 안에만 저장되고, 기기 사이 동기화는 백업 파일(.zip)로 해요.

## 1. GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만들어요. 예: `atelier`
   - 무료 계정이라면 **Public**으로 만들어야 Pages를 쓸 수 있어요.
   - 공개되는 건 앱 코드뿐이에요. 내가 넣은 이미지나 태그는 내 기기 밖으로 나가지 않아요.
2. 저장소 화면에서 **Add file → Upload files**를 누르고, 이 폴더 **안의 내용 전체**를 끌어다 놓은 뒤 **Commit changes**를 눌러요.
   - `index.html`이 저장소 맨 위(루트)에 있어야 해요.
   - Finder에서는 `.nojekyll` 파일이 숨겨져 보여요. `⌘ + Shift + .`을 누르면 보이고, 없어도 앱은 동작해요.
3. 저장소의 **Settings → Pages**로 가요. **Source**를 `Deploy from a branch`로, 브랜치를 `main` / `/ (root)`로 정하고 **Save**를 눌러요.
4. 1~2분 뒤 `https://<깃허브아이디>.github.io/atelier/` 주소로 열려요.

터미널을 쓴다면 이렇게 올려도 돼요.

```bash
cd atelier
git init && git add . && git commit -m "Atelier"
git branch -M main
git remote add origin https://github.com/<깃허브아이디>/atelier.git
git push -u origin main
```

## 2. 아이폰에 설치하기 (꼭 해 주세요)

Safari로 위 주소를 연 뒤 **공유 버튼 → 홈 화면에 추가**를 눌러요.
iOS Safari는 홈 화면에 추가하지 않은 사이트의 저장 데이터를 일정 기간이 지나면 지울 수 있어요. 홈 화면 앱으로 쓰면 이 문제가 없어요.

## 3. 동기화하는 방법

| 맥 (등록용) | 아이폰 (조회용) |
|---|---|
| 오른쪽 위 ⚙︎ → **백업 파일 만들기** | ⚙︎ → **백업 파일 선택** |
| 저장 위치로 **iCloud Drive**를 고르기 | iCloud Drive에서 방금 만든 zip 고르기 |
| | **전체 교체**(권장) 누르기 |

- ⚙︎ 아이콘에 금색 점이 보이면 마지막 백업 이후 바뀐 내용이 있다는 뜻이에요.
- **합치기**는 양쪽 기기에서 모두 수정했을 때 써요. 항목마다 더 최근에 수정된 쪽을 남기고, 삭제한 기록도 반영해요.
- 맥에서는 zip 파일을 창에 끌어다 놓아도 불러오기가 시작돼요.

## 4. 사용법

**작가 탭**
- 이미지를 창에 끌어다 놓으면 등록 창이 열려요. 이미지에 NovelAI 메타데이터가 있으면 작가 태그를 찾아서 자동으로 채워요.
- 작가 상세 화면이 열려 있을 때 이미지를 끌어다 놓으면 그 작가의 화풍 이미지로 추가돼요.
- 첫 화면 위쪽에 폴더 카드(예: 반실사)가 보이고, 누르면 그 폴더 안의 작가만 열려요. 작가 하나를 여러 폴더에 넣을 수 있어요.
- 폴더는 '새 폴더' 카드로 만들거나, 작가 화면의 '폴더' 칸에 이름을 입력해서 지정해요. 폴더 안에서 등록한 작가는 그 폴더에 자동으로 들어가요.
- 폴더 카드는 끌어서(아이폰은 길게 누른 뒤 끌어서) 순서를 바꿀 수 있어요. 순서도 백업 파일에 함께 저장돼요.
- 폴더 안에서도 카드를 끌어서 순서를 바꿀 수 있어요(정렬: '직접 순서'). 맨 앞에 있는 항목의 이미지가 폴더 썸네일이 돼요.
- 즐겨찾기한 항목은 '즐겨찾기' 폴더에 자동으로 모여요.
- 폴더 안에서 연필 아이콘을 누르면 이름을 바꾸고, 휴지통 아이콘을 누르면 폴더를 지워요(작가는 지워지지 않아요). 그림체 탭도 똑같이 동작해요.

**그림체 탭**
- NovelAI 원본 PNG를 끌어다 놓으면 프롬프트, 캐릭터 프롬프트, UC 프롬프트, 생성 설정을 읽어 와요.
- **전체 텍스트** 보기: 읽어 온 내용을 그대로 보여주고, 항목마다 복사할 수 있어요.
- **작가 태그** 보기: `artist:`가 붙은 태그와, 작가 갤러리에 등록된 태그만 모아서 가중치와 함께 보여줘요. 누르면 원래 문법 그대로 복사돼요(`1.2::artist:xxx::`, `{artist:xxx}` 등). 갤러리에 없는 작가는 바로 추가할 수 있어요.
- 같은 이미지를 다시 넣으면 중복으로 보고 건너뛰어요.

**태그 탭**
- 위쪽에서 **실사용 / 편집** 모드를 바꿔요.
- **편집 모드**
  - '구역 추가'로 구역(예: 구도, 표정)을 만들고, 구역마다 카드와 세트를 추가해요.
  - 줄마다 이미지, 이름, 태그, 구역을 정해요. 왼쪽 점 여섯 개를 끌어 순서를 바꿔요.
  - 카드 줄의 ▸를 누르면 **변형 태그**(이름 · 태그)를 넣을 수 있어요. 세트 줄의 ▸를 누르면 **선택지**를 넣을 수 있어요.
- **실사용 모드**
  - 카드를 누르면 태그가 복사돼요. 카드의 **+** 를 누르면 아래 트레이에 담겨요.
  - 변형이 있는 카드(+2 같은 표시)를 우클릭하면(아이폰은 길게 누르면) 변형 목록이 열려요.
  - 세트를 누르면 선택지가 뜨고, 여러 개를 골라 고른 순서대로 복사하거나 트레이에 담을 수 있어요.
- **트레이**
  - 칩을 클릭하면 가중치 −0.1, 우클릭하면 +0.1이에요(아이폰은 탭 −0.1, 길게 누르기 +0.1).
  - '복사'를 누르면 `1.2::tag::, smile` 형식으로 한 번에 복사돼요.
  - 트레이 내용은 저장되지 않아서 앱을 다시 열면 비어 있어요.

**메타데이터가 안 읽힐 때**
사진 앱에 저장하거나 메신저로 보내면 이미지가 JPEG로 바뀌면서 메타데이터가 지워질 수 있어요. NovelAI에서 받은 원본 PNG를 써 주세요.
PNG 텍스트 메타데이터와 알파 채널 스텔스 메타데이터를 둘 다 읽어요.

## 5. 저장하는 것

- 이미지는 원본을 저장하지 않아요. 격자용(긴 변 480px)과 상세용(긴 변 1024px) 썸네일만 WebP로 저장해요.
- 그림체는 썸네일과 메타데이터 텍스트만 저장해요.
- 제목용 세리프 글꼴(Noto Serif KR, SIL OFL 라이선스)은 `fonts/` 폴더에 들어 있어서 처음부터 같은 글꼴로 보여요.

## 6. 앱을 고친 뒤 다시 올릴 때

`sw.js` 맨 위의 `VERSION` 값을 바꿔서(예: `atelier-v1.0.1`) 같이 올려 주세요.
그래야 이미 설치한 기기도 새 버전을 받아요. 보통 앱을 두 번 다시 열면 적용돼요.

## 파일 구성

```
index.html            화면 뼈대
css/style.css         디자인
js/app.js             화면과 동작
js/nai.js             NovelAI 메타데이터 읽기 (PNG 텍스트, 스텔스)
js/tags.js            프롬프트 태그 분리, 가중치 계산, 작가 태그 감지
js/thumb.js           썸네일 생성
js/db.js              IndexedDB 저장소
js/backup.js, zip.js  백업 파일 만들기와 읽기
sw.js                 오프라인 캐시 (PWA)
manifest.webmanifest  홈 화면 앱 설정
```
